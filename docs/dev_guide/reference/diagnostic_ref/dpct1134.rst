DPCT1134
========

Message
-------

.. _msg-1134-start:

The tool cannot deduce the consumer API (``dpct::sparse::csrgemm``) of this API,
and this API has 2 arguments depending on the 8th and the 12th parameters of the
consumer API. Please replace the 2 arguments tagged as ``dpct_placeholder`` with
the corresponding value.

.. _msg-1134-end:

Detailed Help
-------------

The output of ``dpct::sparse::csrgemm_nnz`` is a number representing the NNZ
(number of non-zero). This number is usually used as the size for memory allocation
which will be used by consumer API ``dpct::sparse::csrgemm``. The API
``dpct::sparse::csrgemm_nnz`` has 2 arguments depending on the 8th and the 12th
parameters of the related consumer API ``dpct::sparse::csrgemm``. The tool cannot
detect the relationship. Users need to manually fill in those 2 arguments.
